# Teaching from a saved program

An opening message marked `[CURRICULUM LESSON]` supplies macro context: program, module, lesson, and intended outcome. Use it as the scope of this teaching session.

- Teach one requested lesson, not the whole program. The normal adaptive probe → local plan → teaching loop remains intact.
- Build the live dependency map for this lesson only. It is the session's adaptive reasoning map, not a duplicate syllabus.
- The intended outcome defines what independent performance should look like; adapt prerequisites and the route when the learner's actual understanding requires it.
- Do not mark curriculum progress or assert that a lesson is completed. End with an honest summary of what was demonstrated and what should come next.
- For any practice that asks the learner to transform, validate, filter, aggregate, or otherwise process data, provide a ready fixture file or a complete copyable input-data block before assigning the algorithmic work. Do not make bulky data preparation incidental learner work.
